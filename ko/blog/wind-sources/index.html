이 가이드의 내용

  1. 정보 확인
  2. 평균 이상 보기
  3. 오전 또는 오후
  4. 진행 불가 시

정보 확인

위치, 발표, 예측 기간, 시간대와 단위를 확인합니다. 노트·시속 킬로미터·초속 미터는 다릅니다. 잘린 숫자 대신 원문 링크를 보내세요.

평균 이상 보기

돌풍은 최고값이고 평균은 구간 요약입니다. 모든 초보자에 맞는 기준은 없습니다. 화살표 의미를 이해하고 실제 해안 방향과 연결하세요.

오전 또는 오후

모든 오후가 좋아지지 않습니다. 전체 시간의 변화와 공식 경보를 봅니다. 무역풍은 지역 배경이며 DIMAR, 모델과 현장 관측은 서로 보완합니다.

진행 불가 시

예약에 합의된 대안을 확인하세요. 육상 연습은 교육적으로 적절하고 동의된 경우여야 하며 계약 시간을 자동 대체하지 않습니다. 출국 전 보강 불가도 물어보세요.
